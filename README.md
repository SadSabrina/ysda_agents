## Главная мысль

Когда спрашивают «что повлияло на ответ модели», имеют в виду
**необходимость**: без чего ответ был бы другим. Методы атрибуции — SHAP,
LIME, occlusion — по своей математике меряют **достаточность** и требуют
много прогонов, чтобы что-то утверждать. Это не приближение к необходимости,
а другая величина.

## Главный тейк из презентации

В настоящее время (2026 год, сентябрь) — объяснение агента — не теоретический XAI, а скорее лестница компромисса, между "надежно" и "сложно". Нумеруя ступени, можно описать ее так:

| | что делаешь | прогонов | что получаешь |
|---|---|---|---|
| 1 | инвариант | 1, с заглушкой | держится при любом ответе модели |
| 2 | провенанс | 1, детерминированно | «мог повлиять» по построению, с переблокировкой |
| 3 | контрфактуал | десятки–сотни | измеренная необходимость с интервалом |
| 4 | атрибуция | 2ⁿ | число, отвечающее на другой вопрос |

Спускаться ниже стоит, только когда верхняя ступень невозможна. 

При любых замерах вам важно репортить:

1. **Сколько прогонов** за утверждением? 
2. **Интервал?** Как мы увидели в слайдах — 0 срабатываний из 3 — это не 0 %, а [0 %, 56 %].
3. **Проверяли контрфактуал?** Без этого звена $y$ бы случилась?
4. **Нет ли избыточности?** Если два правила всегда срабатывают вместе,
   важность каждого не определена ни при каком объёме данных.
