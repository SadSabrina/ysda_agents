## Главный вопрос

Вчера был третий из пяти вопросов: **гарантия или сигнал?**

Гарантию проверяют заглушкой: подменяем модель, она выдаёт худшее, что могла
бы выдать, инвариант либо держится, либо нет. Детерминированно, одного
прогона достаточно.

Сигнал заглушкой не проверить. Чтобы заявить «детектор работает», нужно
утверждение «вот это вызвало срабатывание» — причинное. А причинность
меряется через **необходимость**: произошло бы то же самое без этого звена.

Методы атрибуции — SHAP, LIME, occlusion, attention — меряют **достаточность**.
Это не приближение к необходимости. Это другая величина.

## Основной результат за 30 секунд

При `sampling_ratio = 0` occlusion, LIME и Shapley оказываются строго
возрастающими аффинными функциями друг друга. Наклон предсказывается
в закрытой форме:

```
lime_i = [w / (w + alpha)] * occlusion_i + c,   w = (n-1)/n
```

Для n = 4 и alpha = 1 это ровно **3/7 = 0.428571**. Измеренное значение —
0.4286. Корреляция между методами равна 1.0000000000 не потому, что так
совпало, а потому, что это одна функция в трёх масштабах.

Шеплевская нормировка при этом принудительно обнуляет минимальный
инструмент: аксиома dummy «выполняется» ровно для одного инструмента
на промпт, случайно.

## Что забрать на хакатон

Оба кейса — сенсор на рабочей станции и агент-ревьюер — требуют предъявить
причинную цепочку: этот источник вызвал это действие, это правило дало этот
вердикт. Четыре вопроса к такой цепочке:

1. **Сколько прогонов** за утверждением? Один — не измерение.
2. **Какой интервал?** Ноль срабатываний из трёх — это не 0 %, а [0 %, 56 %].
3. **Проверяли контрфактуал?** Без этого звена утечка бы случилась?
4. **Нет ли избыточности?** Если два правила всегда срабатывают вместе,
   важность каждого не определена ни при каком объёме данных.

`sanity_kit` отвечает на 1, 2 и 4 из коробки:

```python
from sanity_kit import measure_necessity, bootstrap_order_prob, redundant_groups
```
